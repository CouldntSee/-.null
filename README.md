# `./null`

An ESP32-based wireless security and electronic warfare research project.

## About

`./null` is a two-person Computer Engineering project focused on exploring:

* ESP32 firmware
* Wireless communication
* RF and signal concepts
* Embedded security
* Hardware experimentation

The project is being developed as a functional prototype with the goal of eventually becoming a physical product.
